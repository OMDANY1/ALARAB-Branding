# Absolute Rules

Never redesign the logo.

Never modify typography inside the logo.

Never distort brand colors.

Never use random stock graphics.

Never generate a generic restaurant website.

Never use colorful gradients.

Never use neumorphism.

Never use glassmorphism.

Never use playful illustrations.

Never create unnecessary decorations.

Never overcrowd layouts.

Always prioritize whitespace.

Always prioritize storytelling.

Always prioritize premium editorial design.

Always use uploaded references before inventing new ideas.

If a design decision is unclear, follow the uploaded references.

When in doubt,

Less is better.
